# 2026.279.1455 — feat(doctor): probe for the VM build's ISO-builder prerequisite

## Summary

`charly vm build` renders the cloud-init NoCloud seed ISO via
`sdk/vmshared/cloud_init_iso.go` `WriteSeedISO`, which requires **any** of
`xorriso` (preferred), `genisoimage`, or `mkisofs` on PATH. The doctor's "Virtual
Machines" section checked `qemu-system-*`, `qemu-img`, `virtiofsd`, `virsh` and the
libvirt socket — but **not** an ISO builder. A host the doctor reported green could
therefore build the entire rootfs + disk + bootloader + initramfs (≈4 min) and then
fail at the **very last step**.

This adds:

- **`checkISORunner`** — accepts any of the three builders (naming which one
  satisfied it), mirroring `checkVirtiofsd`'s multi-location probe; reports missing
  with the `xorriso` install hint otherwise.
- **`data.yml`** — the `xorriso` install hint (Arch ships it in `libisoburn`;
  Fedora/Debian package it as `xorriso`).
- **Tests** — `TestCheckISORunner` (found via a non-preferred builder / missing) and
  the `InstallHints` count + entries.

Closes #11.
